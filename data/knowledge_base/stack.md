# 栈（Stack）

## 一、栈的基本概念

### 1.1 定义
栈是一种操作受限的线性表数据结构，它只允许在表的一端进行插入和删除操作。这一端称为栈顶（Top），另一端称为栈底（Bottom）。栈中的元素遵循后进先出（LIFO, Last In First Out）的原则。

### 1.2 核心特性
- **后进先出（LIFO）**：最后进入栈的元素最先被移除
- **操作受限**：只能在栈顶进行插入和删除操作
- **栈底固定**：栈底在整个栈的生命周期中保持不变
- **空栈**：栈中没有元素时称为空栈

### 1.3 类比理解
栈的操作类似于一叠盘子：
- 只能从最上面取盘子（出栈）
- 只能往最上面放盘子（入栈）
- 最先放的盘子被压在最下面，最后才能被取出

## 二、栈的基本操作

### 2.1 核心操作
1. **初始化栈（InitStack）**：创建一个空栈
2. **销毁栈（DestroyStack）**：释放栈占用的存储空间
3. **入栈（Push）**：在栈顶插入一个新元素
4. **出栈（Pop）**：移除栈顶元素并返回其值
5. **取栈顶元素（GetTop/Peek）**：获取栈顶元素但不移除
6. **判空（IsEmpty）**：判断栈是否为空
7. **获取栈大小（Size）**：返回栈中元素的个数

### 2.2 操作说明
- **入栈操作**：将新元素添加到栈顶，栈顶指针向上移动
- **出栈操作**：移除栈顶元素，栈顶指针向下移动
- **取栈顶操作**：仅读取栈顶元素，不改变栈的结构

## 三、栈的实现方式

### 3.1 顺序栈（基于数组实现）

#### 3.1.1 结构定义
```c
#define MAX_SIZE 100
typedef struct {
    ElemType data[MAX_SIZE];  // 存储栈元素的数组
    int top;                  // 栈顶指针
} SqStack;
```

#### 3.1.2 栈顶指针设计
顺序栈有两种常见的栈顶指针设计方式：
- **top指向栈顶元素**：初始值为-1，栈空时top=-1
- **top指向栈顶元素的下一个位置**：初始值为0，栈空时top=0

#### 3.1.3 基本操作实现
- **初始化**：设置top的初始值
- **判空**：检查top是否等于初始值
- **判满**：检查top是否达到数组边界
- **入栈**：先增加top，再存储元素（或先存储元素，再增加top）
- **出栈**：先获取元素，再减少top

#### 3.1.4 优缺点
**优点**：
- 实现简单，代码简洁
- 随机访问效率高
- 内存连续，缓存友好

**缺点**：
- 空间大小固定，需要预先确定容量
- 可能出现栈满的情况
- 空间利用率可能不高

### 3.2 链栈（基于链表实现）

#### 3.2.1 结构定义
```c
typedef struct StackNode {
    ElemType data;            // 数据域
    struct StackNode *next;   // 指针域
} StackNode, *LinkStack;
```

#### 3.2.2 实现要点
- 通常采用头插法实现，新节点插入到链表头部
- 栈顶指针指向链表的第一个节点
- 不需要设置栈满条件，动态分配内存

#### 3.2.3 基本操作实现
- **初始化**：创建头节点或设置栈顶指针为NULL
- **入栈**：创建新节点，插入到链表头部
- **出栈**：删除链表头部节点，释放内存
- **判空**：检查栈顶指针是否为NULL

#### 3.2.4 优缺点
**优点**：
- 动态分配内存，理论上不会栈满
- 空间利用率高
- 适合元素个数不确定的场景

**缺点**：
- 需要额外的指针空间
- 内存不连续，缓存性能较差
- 实现相对复杂

### 3.3 共享栈（双栈共享空间）

#### 3.3.1 设计思想
共享栈允许两个栈共享同一段连续的内存空间：
- 栈1的栈底在数组的起始位置（低地址）
- 栈2的栈底在数组的末尾位置（高地址）
- 两个栈的栈顶向中间延伸

#### 3.3.2 结构定义
```c
#define MAX_SIZE 100
typedef struct {
    ElemType data[MAX_SIZE];  // 共享的存储空间
    int top1;                 // 栈1的栈顶指针
    int top2;                 // 栈2的栈顶指针
} SharedStack;
```

#### 3.3.3 判空和判满条件
- **栈1判空**：top1 == -1
- **栈2判空**：top2 == MAX_SIZE
- **栈满条件**：top1 + 1 == top2

#### 3.3.4 优缺点
**优点**：
- 空间利用率高，适合两个栈空间需求互补的场景
- 避免了内存碎片
- 动态平衡，一个栈增长时，另一个栈可以收缩

**缺点**：
- 仅适用于两个栈的情况
- 实现相对复杂
- 需要同时管理两个栈顶指针

## 四、栈的应用场景

### 4.1 表达式求值

#### 4.1.1 中缀表达式转后缀表达式
**转换规则**：
1. 遇到操作数，直接输出
2. 遇到左括号，压入栈中
3. 遇到右括号，弹出栈中元素直到遇到左括号
4. 遇到运算符：
   - 如果栈为空或栈顶是左括号，直接入栈
   - 如果当前运算符优先级高于栈顶运算符，入栈
   - 否则弹出栈顶运算符，直到满足入栈条件

**优先级规则**：
- 乘除运算符优先级高于加减
- 括号内的运算符优先级最高

#### 4.1.2 后缀表达式求值
**计算步骤**：
1. 从左到右扫描后缀表达式
2. 遇到操作数，压入操作数栈
3. 遇到运算符，弹出两个操作数，进行运算，结果压回栈中
4. 最后栈顶元素即为计算结果

**注意**：先出栈的是右操作数，后出栈的是左操作数

### 4.2 括号匹配
使用栈检查括号是否匹配：
1. 遇到左括号，压入栈中
2. 遇到右括号，检查栈顶是否为对应的左括号
3. 如果匹配，弹出栈顶；如果不匹配，说明括号不匹配
4. 最后检查栈是否为空

### 4.3 递归的实现

#### 4.3.1 函数调用栈
- 每次函数调用时，系统会创建一个栈帧（Stack Frame）
- 栈帧中保存：返回地址、局部变量、参数等信息
- 函数返回时，栈帧被弹出，恢复调用者的上下文

#### 4.3.2 递归转非递归
使用栈模拟递归过程：
1. 将递归调用的状态压入栈中
2. 循环处理栈中的状态
3. 模拟递归的回溯过程

### 4.4 其他应用场景
- **撤销/重做功能**：使用栈记录操作历史
- **深度优先搜索（DFS）**：使用栈实现非递归DFS
- **浏览器前进/后退**：使用两个栈分别记录前进和后退历史
- **迷宫求解**：使用栈记录路径选择
- **进制转换**：使用栈实现十进制到其他进制的转换

## 五、复杂度分析

### 5.1 时间复杂度
| 操作 | 顺序栈 | 链栈 |
|------|--------|------|
| 初始化 | O(1) | O(1) |
| 入栈 | O(1) | O(1) |
| 出栈 | O(1) | O(1) |
| 取栈顶 | O(1) | O(1) |
| 判空 | O(1) | O(1) |
| 获取大小 | O(1) | O(n) |

### 5.2 空间复杂度
- **顺序栈**：O(n)，n为栈的最大容量
- **链栈**：O(n)，n为栈中元素个数
- **共享栈**：O(n)，n为共享空间的大小

## 六、教学重难点

### 6.1 重点内容
1. **栈的基本概念和LIFO特性**
   - 理解栈的操作受限性
   - 掌握栈顶和栈底的概念
   - 理解后进先出的含义

2. **栈的基本操作**
   - 熟练掌握Push、Pop、GetTop等操作
   - 理解各操作对栈结构的影响
   - 掌握判空和判满的条件

3. **栈的两种实现方式**
   - 顺序栈的数组实现
   - 链栈的链表实现
   - 理解两种实现方式的优缺点

4. **栈的典型应用**
   - 表达式求值（中缀转后缀、后缀求值）
   - 括号匹配
   - 递归的实现原理

### 6.2 难点解析

#### 6.2.1 顺序栈的判空判满
**难点**：栈顶指针的不同设计导致判空判满条件不同
**解决方法**：
- 明确栈顶指针的含义（指向栈顶元素还是下一个位置）
- 根据初始值推导判空条件
- 根据数组边界推导判满条件

#### 6.2.2 表达式转换
**难点**：
- 运算符优先级的处理
- 括号的匹配和处理
- 多位数的识别

**解决方法**：
- 建立运算符优先级表
- 使用左优先原则确保转换唯一性
- 处理多位数时需要拼接数字字符

#### 6.2.3 递归与栈的关系
**难点**：
- 理解函数调用栈的工作机制
- 递归深度与栈空间的关系
- 栈溢出的原因和预防

**解决方法**：
- 通过调试观察栈帧的变化
- 理解每次递归调用都会创建新的栈帧
- 控制递归深度，避免无限递归

#### 6.2.4 共享栈的实现
**难点**：
- 两个栈顶指针的管理
- 判满条件的理解
- 空间动态平衡的实现

**解决方法**：
- 画图理解两个栈的生长方向
- 记忆判满条件：top1 + 1 == top2
- 通过实例验证共享栈的正确性

### 6.3 常见错误
1. **栈顶指针混淆**：不清楚top指向的是栈顶元素还是下一个位置
2. **判空判满错误**：条件判断错误导致栈操作异常
3. **表达式转换错误**：运算符优先级处理不当
4. **递归栈溢出**：递归深度过大导致栈空间耗尽
5. **共享栈边界错误**：两个栈顶指针越界或重叠

## 七、典型例题

### 7.1 括号匹配问题
**题目**：判断一个字符串中的括号是否匹配
**解法**：使用栈存储左括号，遇到右括号时检查栈顶

### 7.2 表达式求值
**题目**：计算中缀表达式的值
**解法**：先转换为后缀表达式，再计算后缀表达式的值

### 7.3 进制转换
**题目**：将十进制数转换为其他进制
**解法**：使用栈存储余数，最后依次弹出

### 7.4 逆序输出
**题目**：逆序输出一个序列
**解法**：将序列元素依次入栈，然后依次出栈

## 八、总结

栈作为一种基础且重要的数据结构，具有以下特点：
1. 操作简单，只有入栈和出栈两种核心操作
2. 实现方式多样，可根据需求选择顺序栈或链栈
3. 应用广泛，在表达式求值、递归实现等领域发挥重要作用
4. 理解栈的LIFO特性是掌握其应用的关键

学习栈时，应重点掌握其基本概念、操作实现和典型应用，通过大量练习加深理解，特别是表达式求值和递归相关的应用。
