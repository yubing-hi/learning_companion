# 图（Graph）

## 一、图的基本概念

### 1.1 定义
图是一种非线性数据结构，由顶点（Vertex）的有穷非空集合和顶点之间的边（Edge）的集合组成。通常表示为 G=(V,E)，其中 V 是顶点集，E 是边集。

### 1.2 基本术语
- **无向图**：图中任意两个顶点之间的边都是无向的
- **有向图**：图中任意两个顶点之间的边都是有向的
- **完全图**：任意两个顶点之间都存在边的图
- **稀疏图与稠密图**：边数远小于完全图的称为稀疏图，接近完全图的称为稠密图
- **权与网**：边上带有权值的图称为网（Network）
- **度**：与顶点相关联的边的数目；有向图中分为入度和出度
- **路径与回路**：顶点序列构成的边的序列；起点和终点相同的路径称为回路
- **连通性**：无向图中任意两顶点间存在路径则称图是连通的；有向图中若任意两顶点间都存在双向路径则称强连通

### 1.3 图的抽象数据类型
- 创建图（CreateGraph）
- 销毁图（DestroyGraph）
- 获取顶点信息（GetVex）
- 设置顶点信息（PutVex）
- 获取第一个邻接点（FirstAdjVex）
- 获取下一个邻接点（NextAdjVex）
- 插入顶点（InsertVex）
- 删除顶点（DeleteVex）
- 插入边（InsertArc）
- 删除边（DeleteArc）

## 二、图的存储结构

### 2.1 邻接矩阵
#### 2.1.1 结构定义
```
#define MAX_VERTEX_NUM 100
typedef struct {
    VertexType vexs[MAX_VERTEX_NUM];    // 顶点向量
    ArcType arcs[MAX_VERTEX_NUM][MAX_VERTEX_NUM]; // 邻接矩阵
    int vexnum, arcnum;                 // 顶点数和边数
} MGraph;
```

#### 2.1.2 特点
- 空间复杂度：O(n²)，n为顶点数
- 适合稠密图
- 判断两顶点是否相邻的时间复杂度为O(1)
- 求顶点度的时间复杂度为O(n)

### 2.2 邻接表
#### 2.2.1 结构定义
```
typedef struct ArcNode {
    int adjvex;                         // 该弧所指向的顶点位置
    struct ArcNode *nextarc;            // 指向下一条弧的指针
    InfoType *info;                     // 该弧相关信息的指针
} ArcNode;

typedef struct VNode {
    VertexType data;                    // 顶点信息
    ArcNode *firstarc;                  // 指向第一条依附该顶点的弧
} VNode, AdjList[MAX_VERTEX_NUM];

typedef struct {
    AdjList vertices;
    int vexnum, arcnum;                 // 图的当前顶点数和弧数
    int kind;                           // 图的种类标志
} ALGraph;
```

#### 2.2.2 特点
- 空间复杂度：O(n+e)，n为顶点数，e为边数
- 适合稀疏图
- 求顶点度的时间复杂度为O(degree(v))
- 判断两顶点是否相邻的时间复杂度为O(degree(v))

### 2.3 十字链表（有向图）
- 结合邻接表和逆邻接表的优点
- 便于求顶点的入度和出度
- 结构较为复杂

### 2.4 邻接多重表（无向图）
- 解决邻接表中同一条边用两个结点表示的问题
- 便于对已访问的边做标记
- 适用于边的操作较多的场景

## 三、图的遍历

### 3.1 深度优先搜索（DFS）
#### 3.1.1 算法思想
从图中某个顶点v出发，访问此顶点，然后依次从v的未被访问的邻接点出发深度优先遍历图，直至图中所有和v有路径相通的顶点都被访问到。

#### 3.1.2 算法实现
- 递归实现或使用栈实现
- 时间复杂度：O(n+e)（邻接表），O(n²)（邻接矩阵）
- 空间复杂度：O(n)

### 3.2 广度优先搜索（BFS）
#### 3.2.1 算法思想
从图中某个顶点v出发，在访问了v之后依次访问v的各个未曾访问过的邻接点，然后分别从这些邻接点出发依次访问它们的邻接点，并使"先被访问的顶点的邻接点"先于"后被访问的顶点的邻接点"被访问。

#### 3.2.2 算法实现
- 使用队列实现
- 时间复杂度：O(n+e)（邻接表），O(n²)（邻接矩阵）
- 空间复杂度：O(n)

### 3.3 遍历应用
- 连通分量的求解
- 生成树的构造
- 路径查找
- 拓扑排序的基础

## 四、图的典型算法

### 4.1 最小生成树
#### 4.1.1 Prim算法
- 从任意顶点开始，逐步扩展生成树
- 时间复杂度：O(n²)（邻接矩阵），适合稠密图

#### 4.1.2 Kruskal算法
- 按边权值递增顺序选择边
- 使用并查集判断是否形成回路
- 时间复杂度：O(e log e)，适合稀疏图

### 4.2 最短路径
#### 4.2.1 Dijkstra算法
- 求单源最短路径
- 要求边权非负
- 时间复杂度：O(n²)

#### 4.2.2 Floyd算法
- 求所有顶点对之间的最短路径
- 允许负权边（但不能有负权回路）
- 时间复杂度：O(n³)

### 4.3 拓扑排序
- 对有向无环图的顶点进行线性排序
- 应用于任务调度、依赖关系处理
- 时间复杂度：O(n+e)

### 4.4 关键路径
- AOE网中从源点到汇点的最长路径
- 用于工程进度安排
- 时间复杂度：O(n+e)

## 五、教学重难点

### 5.1 重点内容
- 图的基本概念和术语
- 图的两种主要存储结构及其实现
- 图的两种遍历算法及其应用
- 最小生成树和最短路径算法
- 拓扑排序和关键路径

### 5.2 难点解析
#### 5.2.1 存储结构的选择
- 难点：不同存储结构的适用场景
- 解决方法：根据图的密度、操作需求选择合适结构

#### 5.2.2 遍历算法的理解
- 难点：递归与非递归实现，状态标记
- 解决方法：通过具体例子演示遍历过程

#### 5.2.3 最短路径算法
- 难点：Dijkstra算法的贪心策略，Floyd算法的动态规划思想
- 解决方法：分步骤演示算法执行过程

#### 5.2.4 拓扑排序的实现
- 难点：入度计算，零入度顶点的处理
- 解决方法：结合具体有向图演示排序过程

### 5.3 常见错误
- 混淆有向图和无向图的存储表示
- 遍历时忘记标记已访问顶点导致死循环
- 最短路径算法中初始化错误
- 拓扑排序时未正确处理入度

## 六、典型例题

### 6.1 图的遍历应用
题目：判断图是否连通
解法：从任意顶点开始DFS或BFS，检查是否访问所有顶点

### 6.2 最小生成树
题目：求连通网的最小生成树
解法：根据图的密度选择Prim或Kruskal算法

### 6.3 最短路径
题目：求城市间最短距离
解法：使用Dijkstra算法（单源）或Floyd算法（多源）

### 6.4 拓扑排序
题目：课程安排问题（考虑先修课程）
解法：构建有向图，进行拓扑排序
