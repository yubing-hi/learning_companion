# 树与二叉树基础

## 一、树的基本概念

### 1.1 树的定义
树（Tree）是一种非线性的数据结构，由n（n≥0）个节点组成的有限集合。当n=0时，称为空树。对于非空树，满足以下条件：
- 有且仅有一个特定的节点称为根节点（Root）
- 除根节点外，其余节点可分为m（m≥0）个互不相交的有限集T1, T2, ..., Tm，其中每个集合本身又是一棵树，称为根的子树（SubTree）

**递归定义**：树的定义是递归的，因为子树本身也是树。

### 1.2 树的基本术语

#### 1.2.1 节点相关术语
- **节点（Node）**：树中的基本单位，包含数据元素和指向子节点的指针
- **根节点（Root）**：树的最顶层节点，没有父节点
- **叶子节点（Leaf）**：度为0的节点，即没有子节点的节点
- **分支节点（Branch Node）**：度大于0的节点，即有子节点的节点
- **内部节点（Internal Node）**：除根节点和叶子节点外的节点

#### 1.2.2 节点关系术语
- **父节点（Parent）**：直接前驱节点
- **子节点（Child）**：直接后继节点
- **兄弟节点（Sibling）**：具有相同父节点的节点
- **祖先节点（Ancestor）**：从根节点到该节点路径上的所有节点
- **子孙节点（Descendant）**：该节点子树中的所有节点
- **堂兄弟节点（Cousin）**：父节点互为兄弟的节点

#### 1.2.3 度和层次术语
- **节点的度（Degree）**：节点拥有的子树个数
- **树的度**：树中所有节点度的最大值
- **层次（Level）**：从根节点开始定义，根节点为第1层（或第0层，视定义而定）
- **深度（Depth）**：节点所在层次的编号
- **高度（Height）**：从该节点到最远叶子节点的路径长度
- **树的高度**：树中节点的最大深度

#### 1.2.4 路径相关术语
- **路径（Path）**：从一个节点到另一个节点的节点序列
- **路径长度**：路径上边的数目
- **简单路径**：路径中节点不重复的路径

### 1.3 树的特点
- **层次性**：节点之间存在明显的层次关系
- **一对多关系**：除根节点外，每个节点有且仅有一个父节点；每个节点可有0个或多个子节点
- **无环性**：树中不存在环路
- **连通性**：任意两个节点之间有且仅有一条路径

### 1.4 树的表示形式
- **直观表示法**：图形化展示节点及分支关系
- **嵌套集合表示法**：用集合的包含关系表示树结构
- **广义表表示法**：用括号表示法描述树结构，如A(B(D,E),C(F))
- **凹入表示法**：用缩进表示层次关系

### 1.5 树的常见应用场景
- **文件系统**：目录树结构
- **组织架构**：公司层级结构
- **家谱树**：家族关系
- **XML/HTML文档**：DOM树结构
- **编译器**：语法分析树
- **决策树**：机器学习算法

## 二、二叉树

### 2.1 二叉树的定义
二叉树（Binary Tree）是n（n≥0）个节点的有限集合，它或者是空集（称为空二叉树），或者由一个根节点和两棵互不相交的、分别称为左子树和右子树的二叉树组成。

**关键特征**：
- 每个节点最多有两个子节点
- 左右子树有严格的顺序，不能互换
- 二叉树可以是空的

### 2.2 二叉树与树的区别
| 特性 | 树 | 二叉树 |
|------|-----|--------|
| 子节点数量 | 任意多个 | 最多两个 |
| 子树顺序 | 无序（除非特别说明） | 严格有序（左、右） |
| 空树 | 通常不考虑 | 可以是空的 |
| 度为2的树 | 不区分左右 | 严格区分左右子树 |

### 2.3 二叉树的五种基本形态
1. **空二叉树**：没有任何节点
2. **仅含根节点的二叉树**：只有一个根节点
3. **右子树为空的二叉树**：只有左子树
4. **左子树为空的二叉树**：只有右子树
5. **左右子树均非空的二叉树**：完整的二叉树

### 2.4 特殊的二叉树类型

#### 2.4.1 斜树
- **左斜树**：所有节点只有左子树
- **右斜树**：所有节点只有右子树
- **特点**：退化为线性结构，性能最差

#### 2.4.2 满二叉树（Full Binary Tree）
**定义**：一棵深度为k且有2^k - 1个节点的二叉树称为满二叉树。

**特点**：
- 所有层的节点数都达到最大值
- 除叶子节点外，每个节点都有两个子节点
- 所有叶子节点都在同一层
- 节点总数为奇数

**性质**：
- 深度为k的满二叉树共有2^k - 1个节点
- 第i层有2^(i-1)个节点
- 叶子节点数为2^(k-1)

#### 2.4.3 完全二叉树（Complete Binary Tree）
**定义**：深度为k，有n个节点的二叉树，当且仅当其每一个节点都与深度为k的满二叉树中编号从1至n的节点一一对应时，称之为完全二叉树。

**特点**：
- 除最后一层外，其他各层的节点数都达到最大值
- 最后一层的节点都连续集中在最左边
- 可能是满二叉树（当最后一层也满时）

**判断方法**：
- 按层序编号，编号连续无空缺
- 不存在某个节点只有右子节点而没有左子节点的情况

**应用**：
- 堆（Heap）数据结构的基础
- 优先队列的实现
- 哈夫曼树的构造

#### 2.4.4 二叉排序树（Binary Search Tree, BST）
**定义**：左子树上所有节点的值均小于根节点的值，右子树上所有节点的值均大于根节点的值，且左右子树也分别是二叉排序树。

**特点**：
- 中序遍历得到有序序列
- 查找、插入、删除操作的平均时间复杂度为O(log n)
- 可能退化为斜树，最坏情况下时间复杂度为O(n)

#### 2.4.5 平衡二叉树（AVL Tree）
**定义**：左右子树的高度差不超过1的二叉排序树。

**特点**：
- 保证树的高度为O(log n)
- 查找、插入、删除操作的时间复杂度均为O(log n)
- 通过旋转操作维持平衡

#### 2.4.6 最优二叉树（哈夫曼树）
**定义**：带权路径长度最小的二叉树。

**特点**：
- 用于数据压缩
- 权值大的节点离根近，权值小的节点离根远
- 不存在度为1的节点

### 2.5 二叉树的重要性质

#### 2.5.1 基本性质
**性质1**：在二叉树的第i层上至多有2^(i-1)个节点（i≥1）

**证明**：数学归纳法
- 当i=1时，第1层只有根节点，2^(1-1)=1，成立
- 假设第i-1层至多有2^(i-2)个节点
- 因为每个节点至多有两个子节点，所以第i层至多有2×2^(i-2)=2^(i-1)个节点

**性质2**：深度为k的二叉树至多有2^k - 1个节点（k≥1）

**证明**：
- 深度为k的二叉树，各层节点数之和为：1 + 2 + 4 + ... + 2^(k-1) = 2^k - 1

**性质3**：对任何一棵二叉树，如果叶子节点数为n0，度为2的节点数为n2，则n0 = n2 + 1

**证明**：
- 设n1为度为1的节点数，总节点数n = n0 + n1 + n2
- 边的总数 = n - 1（除根节点外，每个节点都有一个父节点）
- 边的总数 = 0×n0 + 1×n1 + 2×n2
- 所以：n - 1 = n1 + 2n2
- 代入n = n0 + n1 + n2，得：n0 + n1 + n2 - 1 = n1 + 2n2
- 化简得：n0 = n2 + 1

**性质4**：具有n个节点的完全二叉树的深度为⌊log₂n⌋ + 1

**证明**：
- 设深度为k，则根据性质2：2^(k-1) - 1 < n ≤ 2^k - 1
- 即：2^(k-1) ≤ n < 2^k
- 取对数：k-1 ≤ log₂n < k
- 所以：k = ⌊log₂n⌋ + 1

**性质5**：对于完全二叉树，按层序从1开始编号：
- 如果i=1，节点i是根节点，无双亲
- 如果i>1，节点i的双亲节点是⌊i/2⌋
- 如果2i≤n，节点i的左孩子是2i；否则无左孩子
- 如果2i+1≤n，节点i的右孩子是2i+1；否则无右孩子

### 2.6 二叉树的存储结构

#### 2.6.1 顺序存储结构
**实现方式**：使用数组存储二叉树的节点

```c
#define MAX_SIZE 100
typedef struct {
    ElemType data[MAX_SIZE];  // 存储节点数据
    int size;                 // 当前节点数
} SqBiTree;
```

**存储规则**：
- 根节点存储在data[1]（或data[0]）
- 对于节点i：
  - 左孩子存储在data[2i]（或data[2i+1]）
  - 右孩子存储在data[2i+1]（或data[2i+2]）
  - 父节点存储在data[⌊i/2⌋]（或data[⌊(i-1)/2⌋]）

**优缺点**：
**优点**：
- 实现简单，易于理解
- 随机访问效率高
- 适合完全二叉树和满二叉树

**缺点**：
- 空间浪费严重（对于非完全二叉树）
- 插入和删除操作效率低
- 不适合动态变化的二叉树

#### 2.6.2 链式存储结构

##### 2.6.2.1 二叉链表
**结构定义**：
```c
typedef struct BiTNode {
    ElemType data;              // 数据域
    struct BiTNode *lchild;     // 左孩子指针
    struct BiTNode *rchild;     // 右孩子指针
} BiTNode, *BiTree;
```

**特点**：
- 每个节点包含数据域和两个指针域
- 空指针域较多（n个节点有n+1个空指针域）
- 查找父节点需要从根节点开始遍历

##### 2.6.2.2 三叉链表
**结构定义**：
```c
typedef struct TriTNode {
    ElemType data;              // 数据域
    struct TriTNode *lchild;    // 左孩子指针
    struct TriTNode *rchild;    // 右孩子指针
    struct TriTNode *parent;    // 父节点指针
} TriTNode, *TriTree;
```

**特点**：
- 增加了指向父节点的指针
- 查找父节点的时间复杂度为O(1)
- 空间开销比二叉链表大

##### 2.6.2.3 线索二叉链表（后续详细介绍）

**链式存储的优缺点**：
**优点**：
- 空间利用率高
- 适合任意形态的二叉树
- 插入和删除操作灵活

**缺点**：
- 无法随机访问
- 需要额外的指针空间
- 查找父节点效率低（二叉链表）
